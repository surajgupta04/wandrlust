# 🌍 Wanderlust

Wanderlust is a full-stack web application inspired by Airbnb, built using the **MERN stack** (MongoDB, Express.js, React.js, Node.js). It allows users to list their homes for short-term rental and enables others to browse, rate, and book properties.

---

## 🚀 Features

- 🔐 **User Authentication**  
  - Sign up, login, and secure session management  
  - JWT-based authentication

- 🏠 **Property Listings**  
  - Users can add their homes with images, descriptions, and rental pricing  
  - Listings can be filtered by availability (daily/weekly)

- 📸 **Image Uploads**  
  - Upload property images using cloud storage or local file system

- ⭐ **Ratings & Reviews**  
  - Users can rate and review properties  
  - Only users who have written a review can edit or delete it

- 📅 **Booking System** *(optional enhancement)*  
  - Reserve homes for specific dates  
  - View booking history
